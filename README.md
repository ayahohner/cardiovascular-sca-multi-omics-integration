# Cardiovascular SCA Multi-Omics Integration

A planning workspace for a unified, analysis-ready data plane supporting healthy-versus-sickle-cell-anemia cardiovascular cell-state and fate modeling.

## Original workspace focus

The workspace began with spatially constrained cardiomyocyte–fibroblast signaling after myocardial infarction, with emphasis on how local tissue context shapes intercellular communication. The current project direction is defined in the specification below; no analysis stack has been selected yet.

## Workspace layout

```text
data/       Local inputs and intermediate data (not committed)
notebooks/  Exploratory analyses
src/        Reusable analysis code
results/    Generated figures, tables, and other outputs (not committed)
```

No language, package manager, or analysis framework has been selected yet.

## Project specification

- [Unified data plane for disease-conditioned cellular fate](docs/disease-conditioned-cellular-fate-model.md) — a planning pitch for analysis-ready healthy-versus-sickle-cell cardiovascular evidence and its first fate-model use case; no implementation is included.
