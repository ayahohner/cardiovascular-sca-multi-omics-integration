# Research Modules

This repository contains independent scientific increments, not one generalized data platform.

| Module | Status | Question | Owned artifacts |
|---|---|---|---|
| Endothelial transitions | Released MVP | Which healthy heart-and-lung endothelial adjacencies are compatible with public SCA-relevant signals? | `config/`, `src/cardio_sca_mvp/`, `docs/`, `results/mvp/` |
| [HSPC fate](hspc-fate/README.md) | v1 specified | Does open human HSPC evidence support a reproducible SCA-associated difference in inferred lineage allocation? | `research/hspc-fate/`, future namespaced data and results |

The modules share no data, analysis code, state vocabulary, estimand, or release gate. A finding in one module cannot validate or alter a finding in the other. Common repository tooling may be reused later only when it does not create a scientific dependency.
